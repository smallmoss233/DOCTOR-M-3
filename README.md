# DOCTOR M-3

> 新一代的《Doctor Who》主题模组——全新的 DOCTOR M，登陆 Minecraft 26.3。

---

## 关于

**DOCTOR M-3**（简称 **DM3**），将把《神秘博士》的塔迪斯，未来还有《神秘博士》的星球/生物，新机制等等内容给带进现代的 Minecraft。

前作 **DM2** 是 AIT 模组的附属扩展。DM3 是一次彻底重启——从附属模组转为独立模组，并基于 DM2 的资产做重新设计与扩展。

---

## 功能

### 🚪 门与传送

- **外门 / 内门双方块** —— 各自绑定 TARDIS 的内外端
- **走过去即传送** —— 门开着时踏入即触发，关门状态下无反应；
  进门落内门正面、面朝房间，出门落外门正面、面朝外界
- **开关门联动** —— 无论点内门还是外门，两侧状态同步切换
- **备用门** —— 玩家在 TARDIS 内手动放置的内门自动登记为备用门；
  真门被破坏时，最早的备用门自动升格为真门
- **真门自愈** —— 真门被世界编辑（`/fill`、Axiom 等）替换或删除时，
  重新放置内门即可自动恢复绑定
- **非法位置放置** —— 非 TARDIS 维度里放的内门会立刻被拆掉并提示

### 🛫 飞行

- **推油门即起飞** —— 驻车制动未松开时油门被联锁拦截；油门归零即降落
- **DEMAT / MAT 音效** —— 起飞 18 秒、降落 20 秒，音效与飞行状态逐帧对齐，
  DEMAT 结束瞬间无缝衔接飞行循环声
- **外壳淡出消失** —— 起飞时外壳安静淡出，没有破坏粒子与音效；
  降落时按设定的朝向落回
- **降落朝向罗盘** —— 起飞前在控制台拨好落地方向，北 / 东 / 南 / 西四档
- **手刹与坠机** —— 手刹每拉一档航速减半；飞行中拉驻车制动会坠机

### 🎨 生成与内饰

- **TARDIS 生成器** —— 一键生成整台 TARDIS：独立维度 → 内饰 → 外门；
  内饰就绪前外门保持关闭
- **NBT 内饰模板** —— 内饰由数据包结构模板生成（首发 `classic_interior`）；
  结构方块导出 `.nbt` 放进数据包即可做新内饰，模板里放一个内门方块即可
- **更换内饰** —— 图形界面左右切换预览图选择新内饰；应用后全员离开 TARDIS
  即自动清场重建，完成后通知；中途关服会在重启时续办
- **外门不生成物品** —— 保证 TARDIS 只能通过生成器或命令创建

### 🎛️ 控制台

- **骨骼命名即控件** —— 模型里叫 `ctrl_throttle` 的骨骼自动成为油门，
  模型作者零配置即可让控件生效
- **11 种内置控件** —— 油门、手刹、驻车制动、目的地 X/Y/Z、增量器、
  拉杆、按钮、模式旋钮、降落朝向罗盘
- **四向交互** —— 右键 +1 档、左键 -1 档、潜行右键拉到顶、潜行左键归底；
  无变化不播动画不触发
- **一份档位，全体控制台共用** —— 多台控制台的油门永远指向同一格；
  想要互不相关的控件，用不同类型即可
- **控件外观 JSON 驱动** —— 每个控制台外观独立配置模型 / 动画 / 贴图，
  多外观共存，资源重载即时生效

### 🌌 独立维度

- 每台 TARDIS 一个独立维度：虚空地形、不刷怪
- **STP 无缝传送** —— 预载目标区块，没有加载画面
- 服务器重启后自动恢复，存档完整保留

### 🎮 命令

| 命令 | 说明 |
|---|---|
| `/doctor_m tardis create` | 在玩家前方生成整台 TARDIS |
| `/doctor_m tardis tp [id]` | 传送至自己的 / 指定的 TARDIS |
| `/doctor_m tardis release <id>` | OP：删除指定 UUID 的 TARDIS |
| `/doctor_m tardis info [id]` | 查看 TARDIS 详情 |
| `/doctor_m tardis list` | 列出所有已注册的 TARDIS |
| `/doctor_m tardis door open\|close [id]` | 联动开关内外门 |
| `/doctor_m debug dims` | 列出所有动态维度的状态 |
| `/doctor_m debug save\|reload` | 批量保存 / 卸载（持久化测试用） |
| `/doctor_m debug purge` | 清空所有 TARDIS + 所有动态维度（慎用） |

## 技术栈

### 🛠️ MossLib（核心库）

**MossLib** —— 独立的 Fabric 技术支持库。任何人可自由使用、修改、再分发，
唯一要求是注明 **Small Moss** 为原作者。

DM3 依赖其运行时动态维度管理、声明式网络包与内容注册、
基岩模型 / 动画渲染管线，以及 `/dmbedrock` 模型加载报告命令。

### 🎯 基岩模型集成

- **外观系统** —— 每个外观独立配置几何 / 动画 / 贴图 / 开关门动画，
  留空退化为静态模型
- **门动画路由** —— 按方块朝向旋转模型，按开关状态选播开门 / 关门动画
- **与 Blockbench 的旋转约定完全一致** —— 三轴旋转薄片的还原已逐 cube
  对照工程文件验证
